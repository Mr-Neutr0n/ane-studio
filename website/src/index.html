Before you start

  • Apple Silicon Mac with macOS 15 or newer.
  • Bun and uv for a source install.
  • About 2 GB for development dependencies, plus space for source weights and Core ML packages.
  • Internet for setup and model downloads. Inference runs locally afterward.
  • The first Core ML load can take several minutes to compile, especially with the Neural Engine policy. Token timing excludes this setup.
RUN FROM SOURCE
git clone https://github.com/Mr-Neutr0n/ane-studio.git
cd ane-studio
bun install
bun run worker:setup
bun run dev

A few things worth knowing

Local, with the
details spelled out.

An early developer tool, with honest limits. Issues and contributions welcome.

Does anything run in this website?+

No. This is the website for an Electron desktop app. Model conversion and inference use a Python worker and Apple's Core ML on your Mac. There is no browser inference, upload endpoint, or cloud model backend here.

This site has no analytics scripts, tracking cookies, or account system.

Where do my models and prompts go?+

Model weights, converted packages, prompts, and results stay on your Mac. Hugging Face receives download requests when you fetch a model. Public models do not need a token. Optional Hugging Face credentials use Electron safeStorage and macOS Keychain.

Existing data keeps its original directory and app ID across updates.

~/Library/Application Support/ANE Studio/

Read the app privacy details

Can I use any Hugging Face model?+

No. ANE Studio needs an explicit architecture adapter and a passing conversion for the checkpoint you use. Unsupported architectures fail before weight downloads. Tiny random models test a converter; they do not prove that a useful checkpoint works.

The public model list above only includes checkpoints with recorded evidence. ANE Studio does not load remote custom model code.

Is this a full-size chat assistant?+

No. ANE Studio is a small-model conversion and measurement tool. The current graph has a fixed 64-token context and recomputes it for each generated token. There is no stateful KV cache yet. Keep prompts and responses short.

Local smoke timings are useful for choosing a policy on your Mac, not ranking Apple hardware or model quality.

Is the Mac app signed?+

Current builds are unsigned and not notarized. macOS can show a Gatekeeper warning for downloaded builds. Check the release instructions and verify checksums before opening a package. Do not turn off Gatekeeper globally.

The source path above builds locally. Full Xcode is optional for app development, but required for Instruments profiling and observed accelerator evidence.

What's open source?+

ANE Studio's code is MIT licensed. Downloaded models keep their own licenses and use terms. The repository name and data path are ane-studio and ANE Studio.
